# 0.12.0 minor 发布与本机升级

## 概要

用户要求发布新的 minor 版本并更新本机。发布前四处版本文件、最高远端 tag、最近成功的 Release 均为 0.11.0，本机 Homebrew 与 `/Applications/mdnotate.app` 也均为 0.11.0，因此新版本定为 0.12.0。

本次包含已提交的两组功能：有序列表编号参与选择、复制与标注，评论可在侧栏编辑；Obsidian 图片嵌入及本地 vault 附件解析。版本由 `scripts/bump-version.sh 0.12.0` 统一更新。

## 修改的文件

- `package.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock`：版本统一为 0.12.0。
- 本文：记录发布范围、已完成预检及发布后的核对方式。

## 发布前验证

- `mise exec -- pnpm test`：33 个测试文件、482 个测试通过。
- `mise exec -- pnpm build`：TypeScript 检查与生产构建通过；Vite 仍提示单个 chunk 超过 500 kB。
- `cargo test --manifest-path src-tauri/Cargo.toml -p mdnotate-cli`：111 个测试通过。
- `bash scripts/build-cli.sh` 后运行 `cargo test --manifest-path src-tauri/Cargo.toml`：52 个 app 测试通过。

## 发布后核对

此记录随版本提交，以下步骤在推送 tag 后执行，实际结果以 workflow、本机安装及本地日志为准：

1. 推送 master 与 `v0.12.0`，跟踪 [release workflow](https://github.com/reorx/mdnotate/actions/workflows/release.yml) 至结束。
2. 核对 [v0.12.0 Release](https://github.com/reorx/mdnotate/releases/tag/v0.12.0) 的 universal dmg 和 Homebrew cask 的版本、sha256。
3. 用 Homebrew 将本机更新至 0.12.0，检查已安装 app 的版本、Developer ID 签名、公证票据、Gatekeeper 评估和内嵌 CLI 架构及版本。
4. 本次下载、签名检查与安装验证的本地日志归档至 `tmp/2026-11-02-release-0.12.0/`。

## 注意事项

只安装 CI 发布的签名、公证产物。本地预检生成的 CLI 没有签名，不用于替换正式版。tag 指向包含新版本号的提交；已发布的产物不覆盖。

## 遗留问题

已有的 Dock 退出未保存编辑丢失、窄窗口标题重叠继续保留在 `kb/known-issues.md`。编辑模式及有序列表、侧栏评论的部分 WKWebView 人工验收仍列在 `kb/next-up.md`，本次发布预检不替代这些人工操作。
