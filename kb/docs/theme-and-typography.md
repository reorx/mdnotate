# 主题、深色模式与排版

写给要新写组件、调颜色或动排版的人：深色模式为什么不用 `dark:`、新组件该用哪些颜色、排版的数值从哪来。

## 深色模式：反转调色板

深色模式不是给每个组件补 `dark:` 变体，而是**重新定义整条 neutral 色阶**。Tailwind v4 的颜色都编译成 CSS 变量，所以在 `.dark` 下重定义这条色阶，就一次性翻转了全部组件的颜色，组件的 class 一处不用改。

成立的前提：本项目把 neutral 当作一条严格的「离页面底色多远」的阶梯来用。

| 档位 | 用途 |
|---|---|
| 50 | 侧栏底 |
| 100 | hover |
| 200–300 | 边框 |
| 400–500 | 弱文字 |
| 700–800 | 强文字 |

**新写组件沿用这套阶梯就自动有深色，不要再补 `dark:`。**

### 三类例外

1. **页面底和浮层底有专门的 token。** 白色既是页面底，也是琥珀按钮上的文字色，所以白色本身动不得。页面底与内凹的输入框用 `bg-page`，浮在上面的弹窗与选中的分段用 `bg-raised`。
2. **琥珀和红色的底色与文字，深色下两头对调。** `amber-50/100/200`、`red-50/200` 是底色，`amber-700`、`red-700` 是它们上面的字。
3. **纯前景色原样不动**（`amber-400/500/600`、白色）。想要在深浅两色下都成立的淡色前景，写带透明度的（如 `amber-500/30`），不要去借 `amber-200` 这类会被翻转的档位。

正文排版的颜色全部是 `--prose-*` 变量，深色下给第二套。

唯一用到 `dark:` 的地方是禁用按钮的不透明度：同一个 40% 压得住白底，压不住近黑的底。

### 深色下的高亮

标注库的高亮层用正片叠底混合，在深色底上等于隐形（暗乘暗只会更暗），深色下换成滤色，不透明度也跟着提高。库还全局注入了一条很淡的蓝色选区样式，深色下几乎看不见，也一并覆盖了。

## 主题切换

主题偏好有三个值：跟随系统、浅色、深色。切换有三处副作用，全部由 `theme` 模块统一落地：

- 根元素上的 `.dark` class —— 驱动样式表。
- `color-scheme` —— 驱动样式表够不着的滚动条、光标、滑块轨道。
- 原生窗口的主题 —— 驱动右键菜单、文本选择菜单、窗口控制按钮。传 `null` 才是「跟随系统」。

设置原生窗口主题需要 `core:window:allow-set-theme` 权限，它不在默认权限集里。

把窗口设成深色会连带把 webview 的系统偏好查询也改成深色。不会自锁：只有偏好是「跟随系统」时才去读那个查询，而那时窗口主题正是 `null`。

### 第一帧就要对

真正的设置在异步 IPC 后面，等它回来再上主题会在冷启动时闪白。所以主题偏好额外在 `localStorage` 存一份同步可读的镜像，在界面渲染之前就应用。

代价是 **store 里主题的初始值必须从这份缓存读，而不是用默认值**。同步主题的逻辑会把当前值写回缓存；如果它带着默认值「跟随系统」先跑一轮，就会在真实设置读到之前把缓存里的偏好覆盖掉。浏览器模式下缓存就是存储本身，偏好会被永久抹掉。

缓存的 key 和编码与设置模块的浏览器降级完全一致，两条路径写的是同一个东西，有测试锁住。

## 排版

默认刻意紧凑（15px 字号、1.6 行高），追求信息密度而非留白。

字号、行高、栏宽三项可在设置页调，**Markdown 与纯文本各存一套**。设置页两个 tab，打开时默认停在当前文档的那一套。

### 数值只有一条传导链路

排版设置 → 三个 `--prose-*` 自定义属性 → 写在正文滚动容器的 inline style 上。设置页的预览块用同一个函数，所见即所得。

**默认值只写在 `DEFAULT_TYPOGRAPHY` 一处，样式表里不留第二份。** 所以排版相关的样式用的是不带 fallback 的 `var()` —— 新增渲染正文的地方，必须挂在一个提供了这三个变量的节点下。

### 其它细节

- 正文样式内部全用 `em`，改根字号整套层级自动等比缩放。
- 代码块的行高是「正文行高减 0.1」。刻意的是那 0.1 的差，不是绝对值。
- 栏宽单位是 rem，不随字号联动。滑块最右一格表示「占满」。
- 正文左右的内边距恒定，不参与调节。
- 排版滑块即时生效，防抖 200ms 落盘。离开设置页时会把未落盘的改动写下去，否则「拖完立刻点返回」会丢最后一次。

## 在浏览器里验收深色

深色模式可以不启动 Tauri 验收：只跑前端，用 agent-browser 模拟系统偏好（`agent-browser set media dark|light`）。headless Chrome 默认就是深色。
